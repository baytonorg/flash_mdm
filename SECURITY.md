# Security policy

Flash MDM manages enterprise Android devices and may be deployed with access to
credentials, device information, and customer data. Please report suspected
security vulnerabilities privately; do not open a public issue or pull request.

## Reporting a vulnerability

Email [jason@bayton.org](mailto:jason@bayton.org) with:

- a clear description of the issue and its impact;
- affected versions, deployment modes, or API routes;
- reproducible steps or a proof of concept; and
- any suggested remediation, if available.

Please avoid accessing customer data, disrupting service, or attempting to use
credentials you may encounter. We will acknowledge reports and coordinate a
remediation and disclosure plan with you privately.

## Supported versions

Security fixes are made on the `main` branch and released through the documented
VPS and Netlify deployment paths. Users should run the latest supported release.
